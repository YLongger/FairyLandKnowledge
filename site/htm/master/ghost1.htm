﹝一般魔王﹞　﹝任務魔王﹞ 

惡 靈 攻 略

我是一個刀戰跟一個闇法就去打了 ( 兩人都 lv 46 )

因為很確定他是闇屬性，所以開打前當然是先讓我刀戰武化光屬性的寵，
開打時 ... 幾隻小嘍囉用個大地斬就解決了，就看到他用一些闇系的法術 ...
感覺挺爛的，只是他閃避率真的太高了，三連擊幾乎只打到一下 ...

我叫火瓢出來放銷熔術降他防 ( 一定要降 ! ! )，闇使叫寶石獸補血

突然 ... 他使用了空間爆裂術跟生命奪取 ... " 碰 !! " 700 ~ 800 ... O_o ...

順間我的火瓢就掛了 ... 後來它打我一下也是 700 ~ 800 ( 指用法術而言 )

他的普通攻擊有 350 左右，所以闇使還好之前有放攻擊下降 ... 

還好光武化剋他加上又有用降防 ~ 一擊都有 600 ~ 700 ... 

所以很勉強把他解決了 ~ 現在真的感受到一定要有木寵放禁咒 ...

不然魔王的法術根本是強得不像話 ... 而且最好帶個補血藥水 ...

光靠光寵補來不及呀 .... 一擊 700 ~ 800 差不多被打兩三下就死了吧 ...

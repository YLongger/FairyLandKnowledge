像我21xxx只要花1000塊而已 (最少應該還是要1000吧?)

所以現在聲望變得比較重要了，一進去逛一逛 ... 嘩 !? 碰到魔王喔 ...
一次兩排各五隻 ... 一共十隻怪 = = ... lv46 - 50 都有 ~

怪的種類有很多種，屬性更是七種都有了 -.- ~ 根本沒辦法找出專剋的寵來使用 (鎧或武化...)
所以只好選對我最有力的寵來武化打了 ... 法師清怪效率還是不錯，大地之怒都有不錯效果 !

不過要注意的是 lv46 - 49 的怪強度差不多 ... 但是一碰到 lv50 的怪 !!!
就突然變很多了 ... = = ... (難到是幻獸50級會轉職嗎 XD)

總之不知道怎麼設定的，lv50的強度跟49是差很多滴 ~

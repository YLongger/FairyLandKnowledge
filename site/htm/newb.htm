《 聲明區 》
站長先要在這邊聲明一下

本區裡面的文章有些都是出自於遊戲基地 及巴哈姆特童話討論區，因為是邊看精華區邊截取出站長自己覺得對各位有幫助的文章，所以有時無法一直去基地波文徵求作者同意轉 載，所以每篇文章都會註明作者 ( 或是整理者 ) 在基地的 ID。

每個人的問題都不會是一樣的，所以這裡也只是給大家一個大概的方向，遊戲自己玩得開心就好，別人的意見參考與 否還是要看你自己，但是這邊要提醒的是在這找不到你要的答案，你也可以去別的單元找找唷 ~ ( 像是童話介紹呀 資料下面的選項 ) 相信 本站收集整理的資料不會讓你失望才是 ^^

原本只想做新手區的，不過整理整理看一看基地的精華區，實在是太多前輩們留下很多寶貴的資料，所以站長決定把這邊改名為 文章的整理區，也算是基地精華區的網頁版吧 ... 不過也不是全部都搬過來，站長有把它分類再加以取捨的 ~ 希望能對各位有幫助。

如果對這邊的轉載或是說明有任何疑問或是不願意轉載請來信跟站長說一聲，我會馬上把它砍掉的。

最近一些新文章都是站長自己寫的，或是在童話論壇轉載來的，希望大家能繼續提供好文章造福大家 : )

若是有玩家想要提供些什麼自己寫的文章或心得，歡迎寄信給站長，好文章就是要放上來給大家分享的 ^^

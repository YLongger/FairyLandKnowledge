2005 / 1 / 11 官網更新
以下是官方的說明： ( 1 ) 離婚小惡魔在巴格達城某民宅內為大家服務。 ( 2 ) 為避免結婚機制遭到濫用，要辦理離婚或解除婚約的玩家，必須先取得特殊物品忘情水。 ( 3 ) 忘情水為稀有物品；玩家可在戰鬥中打敗幻獸岩魔人後，以一定的機率取得。 以下為敗家補充說明： ( 1 ) 離婚小惡魔在巴格達城的 30,159 ( 2 ) 岩魔人出現在『冥界洞窟B2、試煉洞窟B1、試煉洞窟B3』 ( 3 ) 在 2005 / 3 / 15 官方已調整忘情水掉寶機率 ( 原本超超超難打 ... ) 改約為求婚戒台的一半 ( 還是很難打 ... ) ( 4 ) 帶著你的婚約石跟忘情水是解除婚約、帶著婚戒跟忘情水是離婚， 要兩人同時在離婚小惡魔前才能辦好手續 ( 一人有忘情水就可以了 ) ( 5 ) 如果離婚的角色，身上會多一個『破碎的心』物品 感謝 彩虹城伺服器 天使任務 提供

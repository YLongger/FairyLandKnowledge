第一步 - - - 開始求婚囉 !!!

首先，先準備好求婚戒台跟一顆鑽石來到第二伺服器 ( 譬如安徒生就到安 2 ) 的吉恩村 ( 7,145 )，進入小屋裡，再點一下小屋裡的傳送石即可到達甜蜜天空。一定要在第二伺服器喔，否則小天使會沒反應的 ~

到甜蜜天空找戒指小天使，他就會將你的求婚戒台跟鑽石合為求婚戒指，接下來你就可以開始求婚了，別忘了 ~ 戒指只有耐久十次，求十次都被別人拒絕，戒指可是會消失的喔 ... ( 應該不會這麼可憐吧 XD )

點選結婚戒指，輸入對方的暱稱，就可以正式向他 ( 她 ) 求婚囉，可是求婚就跟家族收人那些功能一樣，一定要雙方都在同一伺服器及地方才行喔 ~ 不然系統會說此人不存在 ...

這是對方會出現的視窗 ... 還會寫是『第幾次』使用求婚戒指 =_= ... 所以要是之前求婚很多次不成 ... 會有記錄喔 ...

如果對方接受你的求婚，就會出現這樣的訊息 ^_^
第一步驟算是完成囉，象徵著求婚成功的婚約石也會同時出現在雙方的背包裡囉 ~ 下一步驟就是準備結婚囉 ~

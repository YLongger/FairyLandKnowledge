新區資料片連接介紹
→ 人魚傳說 ←

★ 吉恩村最右上方有傳送師可付費傳往貝伯港，但是很貴，所以還是用走的比較方便，經過尼克草原就可以到達貝伯港了。

★ 到達貝伯港後，找下面的老船長可付費前往米夏島，在米夏島右邊有個傳送點，點一下就可以進入巴斯迷宮B1 ... 一直往裡面走就是 B2 -> B3 -> 趴1 -> ... 不過最後到了趴趴迷宮 B3 要去史蓋窩克海 B1 時，別忘了帶顆氧氣泡泡糖，不然是無法進入的，至於氧氣泡泡糖的取得方法請看文章整理的『人魚傳說新地區』文章。

★ 貝伯港右下角有個傳送師史蓋窩克可以幫你傳送到史蓋窩克海，不過需要一顆氧氣泡泡糖，這個史蓋窩克海跟從米夏島一路殺到最裡面 71 級以上的史蓋窩克海 B1 不一樣，這裡怪的等級是 21 - 25 而已，而且也是人魚傳說任務的主要地點喔！

→ 愛麗夢遊仙境 ←

★ 碗豆湖左下角可以通往夢想花園。

★ 在夢想花園有個傳送師，可以由三大村的傳送點傳送到這，當然也可以由夢想花園傳到三大村，跟一般村莊傳送師一樣，不到十級的玩家可以免費傳送，十級以上就要開始收費。

★ 這裡有個新手小密技 : 不到十級的新手玩家可以利用三大村的傳送仙子先傳到夢想花園，再傳到想要去的三大村，這樣一來想去哪個村就都不用錢囉，很適合初期跑任務用！

★ 在解完東迷路森林的『帽商與三月兔』任務後，就可以點一下夢想花園傳送點傳往東迷路森林的三月兔房間中，不需要再走門之迷宮了，另外在莫名其妙花叢下方有個金盞菊魔王 ( Lv 70 )，打贏可以得到小菊花徽章，帶著徽章就可以從羅比特草原右下傳點免費傳往北貓咪森林。

→ 天方夜譚 ←

★ 到天方夜譚的路有兩條，一是由貝伯港右下找哈丁船長傳往哈辛島，再點一下船長傳到巴斯拉港，巴港往上就是巴格達城了，也就是天方夜譚的主城，四通八達，號稱掛網新聖地。

★ 第二條路就需要『魔毯』，在青蛙沼澤右下方跟神燈沙漠最右方都可以通往飛魚角，然後承坐著魔毯經由飛魚角右邊傳點來到巴斯拉空域，一直往右走就是巴斯拉港了，到而魔毯是在巴格達城裡買，所以也就是說 ... 第一次要去巴格達城的玩家 ( 沒魔毯 )，只能由貝伯港坐船囉。

★ 要回主大陸就要從巴斯拉港回去，你可以從巴斯拉空域走回飛魚角 ( 太遠了 )，第二條路就是花錢由巴港最左下的吉姆船長傳往摩摩島，再點一下船長傳回貝伯港，因為巴格達城沒有三大城的傳送師 ( 花一千元那個 )，所以最好是在巴格達醫院設好點比較方便。

→ 國王的新衣 ←

★ 國王的新衣資料片新地圖只有瓦尼島 ... 跟島正中央的一個地下遺跡迷宮，只能由巴斯拉港 ( 66,40 ) 的艾瑞克船長付錢出發 ( 好貴呀 )，一入島就是 66 ~ 70 的怪 ... 所以這次資料片可以說是為高等級的玩家設的 ... 低等玩家千萬不要來瓦尼島送死喔 !!

→ 綠野仙蹤 ←

★ 在秘密平原最左上方有個傳送石柱，一點就可以來到綠野仙蹤的第一站『彩花村』，雖然是寫村莊，但是會有敵人出現的，等級是 41 ~ 45，至於越往後面的地圖當然等越高囉！

★ 而這次有開放許多高階的產物都可以在這次資料片的地區收集到（掛網啦），詳情請看 工作技能 - 高階技能

→ 姆指姑娘 ←

★ 由木偶山右下就可以來到這次新資料片的起點 - 木偶山山腳，這裡不會遇到怪物，往右上走是進入新的練功區 - 夢奇地，會依照你的等級進入適合的練功區，譬如說 31 級玩家就會進入到 31-40 的練功區、41 級玩家就會進入到 41-50 練功區，但是若等級未滿 31 進入夢奇地也是會來到 31-40 練功區喔，要小心。不過高等玩家也可以進入低等夢奇地，只是要組一個低等的玩家這樣平均等級才會降低，很多幻獸師為了要去低等夢奇地區域抓幻獸，就開了一隻新手分身來組隊進夢奇地

★ 而木偶山山腳右下有個女巫可以買『放大鏡、縮小鏡』，先買一個縮小鏡，來到右下有個小罐頭旁使用，自己就會縮小，這時就可以進入罐頭地道B1 ... 一直來到這次新開放的地區囉 ~ 只是這次並沒有新的產物採集點 :p 大概是因為縮小了所以掛網釣到東西會 ... 不合理吧 @_@ ...

→ 美女與野獸 ←

★ 這次資料片入口是在鳳梨山左邊，一進入遇到的怪是 41~45，然後就按照慣例越來越強 ... 羊角村外圍會有 46~50 的怪，村子裡面不會遇敵，拇指姑娘資料片的區域沒有產物，這次開放的新地區有不少高等產物可以掛喔！！詳情請看 童話攻略 - 工作技能。

★ 值得一提的是這次的練功區『古堡地下迷宮』，若一開始進入遺忘森林左上是不讓你進入普諾特古堡的，要解美女與野獸系列的任務才能進去，所以沒解任務的玩家只好乖乖地由羊角村南方 -> 狂風沙漠 -> 沙漠地城，這樣繞路前往囉

→ 桃太郎 ←

★ 桃太郎資料片是東洋（日本）的故事背景，自然就要坐船到神秘的東方國都囉，所以進到新區域就跟船、海有關，而貝伯港 ( 14,280 ) 以及巴斯拉港 ( 35,78 ) 就是這次新坐船的地點囉

→ 糖果屋 ←

★ 由糖果山左上方就可以進入糖果屋資料片的第一站『登山小徑』，往右上是這張資料片的主打『轉生神殿』也就是轉生機制執行的地方，而登山小徑左上通往葛雷夏村，暫時的休息區 ... 由葛雷夏村左邊可以乘船（木伐）過河，過河就切換到了葛雷夏郊外，這裡就會碰到敵人了 ... 等級都是 130 起跳，所以低等的千萬不要來這邊送死喔 !!

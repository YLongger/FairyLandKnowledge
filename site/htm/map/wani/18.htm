遺跡地下18F
重點提示
18F 一路往左上就可以繞到上面的魔王處了，來到這裡目標就是要打倒魔王繼續前進囉，首先要整頓好團隊的裝備喔 !! 因為這個魔王相當的強，一不小心在這滅團的人可是相當的多呢 ( 站長也常發生這種事 ~ 唉 ~ 太嫩了 ) !!

這個魔王之所以強，就是當他一回合血少 ... 大約三萬以上，下回合就會使出暴怒一擊碎金刀，一刀威力是 ... 四千左右，不過因為可以確定他暴怒一擊一定是用碎金刀，所以你可以事先鎧火，這樣打下來一擊兩千多還不至於一擊殺 ... 但是因為這個魔王敏太快，也有可能你鎧火一開始被他使用召喚冰龍 ... 所以有點碰運氣吧， 趕快讓大家叫出肉盾寵出來擋，最好是有會『犧牲』技能的寵，這樣才有機會救活你。

戰鬥方法還是一樣，速戰速決呀 ~~~ 雖然這魔王只會用魔法攻擊，但是你的闇寵或是水寵千萬不要停止放降物理攻的法術呀 ~ 為什麼呢 ? 因為若是沒辦法很快解決他的話，這隻臭鴨子會變身成『大可魔。FOREVER』，這時他用的就不是法術，而是物理攻擊了，並且血會自動補為 20 萬，還有就是一回合血損太多會放幻空拳 ... 威力也是四千多左右，所以 要是你沒有每回合都讓你的寵放降攻的法術的話，下一回合來不及降到他的攻就被放幻空的話 ... 嘿嘿 ~ 那 ...

之所以要讓寵每回合都降他攻就是為了要讓他在變身的那一回合，寵正好就降到他的攻，因為魔王一定先出手，寵一定慢出手，正好在他變身那回合降到，這樣應該不會太難理解吧 ... 總之變身的王要是被放了浪舞加上虛弱的話，那就跟 15F 魔王一樣，跟小孩子一樣讓你玩了。

遺跡地下21F
重點提示
21F 中間下方是坑錢賣藥跟補血補法的地方，雖然坑錢，但這裡已經是遺跡最後一處可以做補充的地方囉，如果真的彈盡援絕的話就去買吧 ...

魔王 怪醫X 跟 18F 的大可獸‧改很像，一回合受一定的傷就會使用碎金刀，所以請跟 18F 一樣打法 ... 鎧火吧 !!

不過這邊也如同 18F 的魔王，打王時浪之舞 ( 水系 ) 跟虛弱術 ( 闇系 ) 請不要停止放，因為王若變身的話就會開始使用幻空拳 ~ 而第三次變身更是會使用大劍士所有的招式 ... 不過如果你都有一直降他攻的話 ~ 那他最後也只有被打好玩的份 :P

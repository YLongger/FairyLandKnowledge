重點提示
22F 的地圖就是從內到外全部繞一圈 ... 很簡單的迷宮 ~_~

可以不用走這個迷宮 !! ( 感謝許多玩家來信提醒站長 ) 在起點 Start 的地方往下方走，就可以看到這隻臭蟲魔王，點他就可以了 !!

這隻超級臭窩窩蟲魔王 ... 是童話中唯一可以用錢打發的魔王 :Q ... 只是要 50 萬可因 !!! 我想沒人會想給吧 ... 殺殺殺殺 ~

不過當然也不是那麼好殺的 ... 這隻魔王會一直使用超級補血術 ... 一補就十幾萬 = = ... 雖然他只會用一擊一兩千的聖光彈攻擊，但是若隊伍無法一回合給他大傷害的話 ... 就會看到他一直補一直補 ... 怎麼打都打不死 ~

如果這場逃跑或打輸的話，會回到 22F 起點又要重新繞一圈 ~

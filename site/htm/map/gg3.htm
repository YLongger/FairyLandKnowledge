重點提示
準備好就可以跟無尾熊秘書說預約好了進去打魔王。

要記住 !! 預約時隊長不能亂換，不能說 A 跟秘書說預約好了進入魔王房間後再換 B 當隊長，這樣魔王會說你沒預約把你趕回 0 層。還有裡面有人在打也要等，進去裡面發呆太久沒有點魔王戰鬥也會被踢回 0 層喔！！

大可魔不難打，而且打這魔王可以得到職業徽章 ( 換裝用的 )，只要小心他的法術攻擊就好，一擊都是上千的。不過只要團隊實力夠，放個禁咒加上像巫師血液蒸發及闇使生命儀式這樣以對方血量來計算傷害值的法術攻擊 ( 就是敵人血越多打越多 )，很輕鬆就可以解決他了。

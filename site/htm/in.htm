有關幻獸店的幾個功能說明

幻獸封印 : 幻獸太多又不想丟掉就用這個吧， 他會把幻獸又變成封印球 ... 可是跟幻獸師封住的不一樣喔，因為親和度會跟 封前一樣的 ... 當然換主人就不一樣了。所以有時太煩惱要這隻還是要那隻又不想 亂丟 ... 就封起來吧，免得法力一直被幻獸吸吸吸 ...

幻獸棄養 : NPC 小姐會跟你確認大概三次吧，是否真的要棄養 ... 如果 你確定不要這隻寵物，就忍心按下確定吧 ! 棄養後寵物會完全地消失 ~ 也不用收棄養費 ~ 但是想反悔就來不及囉 !!

幻獸的降級 : 簡單的說就是把幻獸降到一級，因為剛抓到的 幻獸屬性都是比較平均，所以若想練出好的寵物 ( 力寵或智寵 ... ) 建議看看幻獸的屬性 再看看要不要降級 ( 一般來說火屬性寵升級偏力 闇屬性偏敏 ... ) ，所以要好好決定，並不 是降了就一定好，不過越高等的幻獸降級後，第一級的屬性總合會比一般的一級寵高出許多。

降級後的屬性計算 : 降級後的初始屬性是這樣算的 :

【該屬性的初始能力 = 2 + 降級前該屬性的數值 / 20】

所以一開始抓到一隻闇黑半龍 ... 力量是 50，把他降級後 ~ 在等級一力量就會是 2 + 2 = 4

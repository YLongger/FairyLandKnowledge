  究極融合

看清楚了！！這就是童話中比四封還要珍貴的超級寶物 -- 生命核心！！

何謂究極融合？就是隨心所欲融出自己想要的寵，看著繼承屬性、物種、成長能力的舉例，老是有許多的失敗成分在裡面，這種究極融法就是將三種的優點合在一起的 究極融合法，所需要的材料當然就是傳說中的生命核心和兩隻寵囉！！

使用生命核心融寵前一定要好好的思考，可不要隨隨便便拿來融呀，譬如說寶石獸 + 火熊利用生命核心是可以輕輕鬆鬆融出四封寵路比火寶石獸，但是這麼一來生命核心的價值就變得跟一顆四封一樣了， 所以擁有生命核心的朋友不妨參考此單元的『繼承成長能力』，相信對你會有很大的幫助。

目前取得生命核心的方法就是之前官方辦的活動還有現在市面上賣的Ｑ卡 ... 也可以說是一種台幣寶物啦，拼命抽Ｑ卡 ... 開箱子能開到嗎 ... 至今尚未有消息傳出 ...

  舉例說明

在此舉此活生生的實例給大家，是由 安徒生 - 小小工頭 玩家提供的資料，『闇貝貝』的融合例子， 所準備的材料有『木頭貝貝一隻、黑狗一隻、生命核心』，至於為什麼用黑狗，因為要融闇系的一定要有隻闇系寵，而黑狗又是屬於三封等級比較高的寵，剛抓到的數值比較好，融出來的闇貝貝起始值會比較高一點，

這時選擇的融合方式是這樣 :

1. 屬性選擇黑狗的闇系

2. 物種選擇貝貝的幻獸種類

3. 成長能力選擇木頭貝貝的成長路線

於是，就這樣，一隻走木頭貝貝成長路線的闇貝貝就出現了！至於為什麼要這樣配 ... 在『繼承成長能力』單元中有提到，就不再重複說明囉。


而這位玩家用的第二個生命核心 ( 有兩個 ... 真羨慕 >_< )，是拿來融出夢幻的闇系暴力寵，所準備的材料是『阿波羅獅一隻、闇黑虎一隻、生命核心』， 由繼承成長能力的說明大家應該可以猜知為什麼要這樣配了吧，目的就是要融出一隻純暴力的闇系武化寵囉。

這時選擇的融合方式是這樣 :

1. 屬性選擇闇黑虎的闇系

2. 物種選擇獅子的幻獸種類
( 老虎也行啦，反正兩種都是偏力，不過闇黑獅是四封寵 ... 比較貴 @@ )

3. 成長能力選擇阿波羅獅的成長路線

當然，生命核心是 100% 的成功率，連傳說中的基因突變也不會發生，所以產生的當然是夢幻的走阿波羅獅路線的暴力寵闇黑獅囉。而這位玩家也將這兩隻夢幻寵給養大讓站長照相， 數值如下 :

　

由數值可以知道闇貝貝升級的走向是木頭貝貝的成長路線，闇黑獅則是阿波羅獅的暴力路線 ( 這隻升的有點不好，不過降級再練一樣還是火系的走向 )，兩隻的屬性數值完全不會因為闇系的偏智而影響， 這就是生命核心的功能及魅力所在呀！！

  其他注意事項

融出闇貝貝是沒有什麼問題啦，不過我想應該有很多人跟站長一開始一樣有個疑問 ... 那就是「為什麼闇系武化寵要融個遊戲中有不稀有的闇黑獅而不融稀有的夢幻闇系卡拉龍 - 霸王龍呢？」

原因就是生命核心雖然威力強大，但是仍有一點點的小限制，那就是兩隻寵本身的素質，請大家再好好看看使用生命核心融合的三步驟，要融成霸王龍需要什麼樣的材料？卡拉龍是一定要的嘛 ... 再來呢？ 要讓這隻融合寵要有火系暴力的走向一定要有一隻火寵 ... 不過問題就來了，一隻光卡拉、一隻火寵，根本沒有闇的屬性，所以生命核心無法從這兩隻寵抓出闇系的屬性來融，融出的不是光寵就是火寵，當然除非你有一隻火卡拉的話 ... 就可以融出 這樣傳說中的霸王龍了，一隻火卡拉 + 一隻闇系寵，屬性選闇、物種卡拉龍、能力是火 ... 不過 ... 遊戲中根本沒有火卡拉龍呀！！所以這也就是為什麼闇系暴力霸王龍目前一顆生命核心融不出來的原因～

當然如果你是有錢人有很多生命核心的話 ... 先融一隻火卡拉再融成暴力霸王龍也行 ... 不過當然是廢話 = =，只要有錢 ... 有那麼多生命核心，你想要什麼寵就有什麼寵 @@ ~

P.s 萬一發現物品準備都齊全卻不能融的情形，就代表該物種未開放囉 ~ 總之遊戲中抓得到的寵就應該可以融得出來 ... 少數新開放的寵例外 ~ 大概就是這樣吧 ~ 之前發生了霸王龍融得出來的 Bug，不過現在已經又被官方修正變不能融囉， 因為霸王龍在遊戲中並未出現 ... 這是官方的理由吧 ~ 大概就是這樣囉 : (

此外，寵物會的技能，就跟你選的物種是一樣的 ~ 譬如說是闇獅子 ~ 他會的就跟獅子會的都一樣，若是會法術的 ~ 那就看是什麼屬性就會什麼屬性的法囉 :)

感謝安徒生 - 小小工頭提供資料

此外，由於之前站長搞錯『成長路線』的意義，由 遊戲基地版主 - 東方霞夢 問過官方之後教站長才了解，原來成長路線是完完全全將幻獸的路線整個搬到另一隻身上 ... 這部份在『繼承成長能力』已有說明，在此轉載東方版主告訴站長的一個教學小故事：「 假設我們使用生命核心想要融出暴力黑綿羊，也就是黑羊 + 火熊這個例子，在選擇屬性跟幻獸種類這兩個部份，只是選擇幻獸的『皮』，真正幻獸本身的內在是在『成長能力選擇』， 只要你選擇能力成長是黑綿羊，那不論牠是紅色或黑色的羊或熊，牠就一定是走黑綿羊純智路線；同樣道理，當你選擇了能力成長是火熊，不論你選擇這個幻獸牠要批著是羊皮還是熊皮，牠日後的成長路線依然會跟火熊一模一樣 」

希望這樣說明大家會了解囉 ^^ ~ 生命核心真是個無價之寶呢 ~

感謝遊戲基地版主 - 東方霞夢提供教學資料

最後一個核心的重點提醒，也是由玩家 小小工頭 發現的核心設計的大重點，那就是如果有玩家想要用兩顆核心來融出心目中想要的寵時，就要特別注意了， 生命核心的成長屬性是就單單只看寵的成長屬性，而不管牠有沒有被改變，譬如先用一顆核心融出純力的闇黑獅，再拿一個 xxx 寵來融，把成長能力選擇這隻闇黑獅，以這樣來看應該這隻寵的 成長路線也是純力才對 ( 因為用純力的闇黑獅 )，但是很抱歉 ... 官方的設定是只要你選擇成長屬性是『闇黑獅』，牠就是獅子偏力闇系偏智這樣走法，並不會是純力的路線，即使你之前把這隻 闇黑獅用核心或是營養劑改變成純力路線也是沒有用 ... 不知道這樣玩家有沒有了解了呢 @@ ~ 融下去官方可是不管的喔 ... >_< ...

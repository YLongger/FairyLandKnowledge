  繼承屬性

除了一切交給上帝的一般融合，難到就沒有方法可以讓融合的結果可以由自己掌握嗎？

不用擔心，接下來就是要教各位如何運用繼承的系統讓我們可以自己選擇融合可能產生的結果，繼承屬性就是保留住融合的兩隻幻獸其中一隻的屬性， 讓你可以確定融出來的結果一定是那種屬性。

不過當然這樣的融法所需要的本錢也要更多，你要準備的東西有「一顆屬性水晶、兩隻幻獸 ( 廢話 )、其中一隻幻獸的卡片」，只是要注意的是， 屬性水晶一定要配上同樣屬性的幻獸卡，譬如說你拿了個綠光水晶，要和火獅跟派艾波，所需要的卡片就一定要是派艾波卡，不能是火獅卡，因為派艾波是木系，綠光水晶也是木系， 這樣才能開始進行融合。

但是還是有很大的機率什麼都沒改變，保持原寵，照上面的例子，拿了火獅跟派艾波去和，雖然說 融出來結果一定是木系，但是不一定會是木獅，還是有很大的機率還是融成原本的派艾波 ... 這是結果相信你也知道，浪費了一顆水晶跟一張卡片還有一頭可憐的獅子， 當然 ... 還是有可能不是木系啦 ... 那就是 ... 提到爛的『基因突變』@@

屬性水晶取得方式請參考童話攻略 -> 掉寶資料 -> 特殊物品

  舉例說明

在這裡舉個『水寶石獸』的融合心得吧，首先要準備的是『寶石獸一隻、積雨雲一隻、淡藍水晶一顆、積雨雲卡一張』，至於為什麼不能用寶石獸卡呢，上面已經說明過了， 這時可能會產生的結果如下 :

1. 積雨雲 ...
( 大失敗，雖然說繼承了水的屬性，但是常發生的就是不變，浪費了前面的材料 )

2. 藍寶石
( 恭喜恭喜，遊戲中沒有出現的稀有可愛藍阿寶就這樣產生囉 )

3. 基因突變 ... 變成一隻完全隨機的寵，也沒有固定是水系
( 是福不是禍，是禍躲不過 )

如何融合以及步驟請參考本單元的『一般融合』，都差不多一樣，之後就不再重複囉

  繼承成長能力

繼承成長能力算是挺夢幻的一種融合方式，就是保留住融合寵其中一隻的成長屬性，你能想像一隻擁有 A 造型的幻獸，升級走的卻是 B 造型幻獸的路線這種夢幻的模式嗎 ( 不管幻獸本身屬性及種類，完全複製另一隻幻獸成長模式 )， 繼承成長能力就是這樣的一種融合方式，所要準備的材料是「兩隻幻獸、幻獸營養劑、欲保留成長路線的幻獸娃娃一個、該幻獸卡片一張」，不過這種融法 目前資料不多，但是在看過前幾篇的教學說明，我想大家也大概可以推知說這個繼承成長能力是怎麼一回事了吧 :)

幻獸營養劑跟幻獸模具的取得方法一樣，目前都是配合官方的活動送出。

若有新的取得方法站長會趕快把它更新到網頁上的，

  舉例說明

在這裡舉個『超體黑綿羊』的融合例子吧，首先要準備的是『黑綿羊一隻、派艾波一隻、幻獸營養劑、派艾波卡一張、派艾波娃娃一個』，因為我希望保留住派艾波的純體成長路線，而又是闇系屬性，這樣會變成黑綿羊走的卻是跟派艾波一樣的純體路線，變成一隻超強的體鎧寵，不用擔心會被任何屬性剋， 當然或許也可以用『隨便一隻闇系寵、木頭貝貝一隻、幻獸營養劑、木頭貝貝卡、木頭貝貝娃娃一隻』，這樣試著融出遊戲中稀有的闇貝貝，不過因為木頭貝貝的卡跟娃娃也算是稀有的寶物 @@，拿來和實在是太 ... 太刺激了，和失敗可是損失慘重呢，加受木頭貝貝又是稀寵不好抓，所以換另一種比較廉價的融合方式，相信聰明的你一定有更划算的融法。

以黑綿羊這個例子，可能會產生的結果如下 :

1. 一隻會走派艾波純體成長路線的黑綿羊
( 大成功，一個外型是黑綿羊的寵物，但是升級卻是跟派艾波長得一樣，而且屬性還是闇系，跟我們期望的一樣 ~ 真是可喜可賀呀 ~ )

2. 一隻會走派艾波純體成長路線的暴力羊
( 這也算是失敗吧 ... 雖然本來暴力羊是體智寵，現在把牠改成純體寵 ... 但是 ... 還是木系呀 @@，那還不如就安份養隻派艾波不就好了 ... 還有轉換回春可用呢 ~ )

3. 派艾波
( 失敗 ... 派艾波本來就是走派艾波成長路線嘛 ... 好像廢話 = = ~ 反正就是浪費了材料 )

4. 一隻會走派艾波純體成長路線的黑皮鳳梨
( 也是大成功，原本黑皮鳳梨會因為闇系的影響變成偏智，現在成長路線變成跟派艾波一樣，就變成純體的闇系寵囉！！ )

5. 基因突變 ...
( 謎 ... 不再提了 @@ )

 當然舉例黑綿羊是希望大家比較好懂，如果是站長要融的話，我會選擇用窩蟲、鳳梨、貝貝這幾類，因為牠們才會轉換和回春，一個好的鎧寵要有轉換回春才方便嘛 ~一個超體黑綿羊如果不會轉換回春不是很可惜呢？


當然上面舉的是純體的融合方式，這是屬於要融出不怕任何屬性剋的肉盾寵或是鎧化寵的方式，對於戰鬥型角色來說 ... 一隻夢幻的武化寵才是最重要的吧，想想看用武化寵的玩家 ... 幾乎全都是火寵， 碰到水的或是土的都有打不痛的困境，要是武化闇系暴力寵或是光系暴力寵不就什麼屬性的敵人都不怕了？所以在這邊也舉一個和出這樣的暴力寵的例子 :

『火熊一隻、光鼠一隻、幻獸營養劑、火熊卡一張、火熊娃娃一個』

1. 火熊
( 失敗 ... 火熊成長路線本來就是火熊嘛 ... 又是廢話 = = ... )

2. 一隻會走火熊純力成長路線的光熊
( 成功囉，光系的純暴力寵，光熊的升級路線變成跟火熊一樣，跟我們期望的也一樣 ~ )

3. 一隻會走火熊純力成長路線的光鼠
( 也是成功！一隻不起眼的光鼠，升級卻跟火熊一樣是純力寵，還有著光系不怕被剋的優點 ... 多夢幻的老鼠呀 ~ )

4. 一隻會走火熊純力成長路線的火焰鼠
( 雖然說火鼠變成跟火熊一樣是很特別啦 ... 但是 ... 都是火屬性的話就跟一般火系暴力寵沒什麼兩樣了吧 ~ 失敗 ~ )

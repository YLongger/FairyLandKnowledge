  何謂融合

簡單地說，就是到花 5000 可因到幻獸店裡將兩隻幻獸融在一起，融合出一隻由這兩隻寵的能力數值平均降到一級的新寵。

至於融合所產生的新寵，則由兩隻寵的屬性、幻獸種類而定，有可能會出現新的屬性寵，也有很小的機率發生突變，融出無法預測的寵物出來。

  融合的好處

1. 融合出新的、稀有的或是高等的幻獸，譬如說將一隻火瓢蟲+一隻褐土獅，就有機會融出一隻一級的火獅 ( 反正融出來的寵一定是一級 )，只要花 兩顆封印石的錢 + 5000 可因的融合費，就可融出一隻三封的阿波羅獅，多划算呀！

2. 當想省下一筆高等的降級費可以利用融合來降級，因為許多純力或是純體的寵剛抓到一定要降級練，不過像 4x 以上的寵一降都要十幾萬的錢，若是抓兩隻一樣的寵來融合， 不但便宜，而且數值也會比直接降級來得好

3. 融出遊戲中沒出現的稀有寵，譬如說水寶石獸，在遊戲中完全無法碰到，自然也就無法補捉，所以唯一想得到的辦法就是靠融合，運氣好讓你融出一隻遊戲中都沒出現的新寵，包你帶在路上走路都有風

  融合的風險

當然，看完了好處之後，現在要看的就是融合可能產生的風險，畢竟沒有那麼好康的事情，融合所會產生的變數是非常大的，在這裡列出幾個比較常見的例子 :

1. 融合並不是可以讓你隨心所欲想要什麼屬性的寵就是什麼寵，譬如說拿一隻紅瓢蟲+寶石獸直接拿去融，就想融出夢幻的四封寵火寶石獸 - 路比，那成功的機率真的是跟中樂透有得拼了， 融合除了會屬性異變之外，最常見的就是什麼也沒變 ... 也就是說拿兩隻 A、B 寵去和，結果融出來的還是一模一樣是 A 或是 B，並沒有那麼完美地 A 屬性跑到 B 身上去，所以融合帶的運氣成份相當重，要融之前別忘了多拜拜呀

2. 融合除了會融出 A、B 有相關的寵之外 ... 還會有很小的機率發生傳說中的〝基因突變〞！融成一隻完全不相干的寵，不過這是福是禍卻還不一定，有許多玩家藉由基因突變反而融出意想不到的稀有幻獸寵， 不過又要期待突變又要期待突變成稀有的寵 ... 你覺得 ... 很容易嗎？

  範例說明

請參考童話攻略 -> 幻獸數值 -> 【融】，裡面都是玩家成功融出的新寵

 剛開放幻獸融合功能的時候，大家都拼命想要和出遊戲中未出現的寵，譬如說藍獅子，由於藍獅子是水屬性，所以就只要拿一隻水寵 + 獅子種類的融， 在這裡舉個『水蜘蛛 + 褐土獅』的例子，因為這兩隻都是一封的低等寵，拿來融是最省錢的了，總不能抓兩隻三封寵來融吧，要是失敗了不就賠大了， 可是會這麼順利一融就融出藍獅子嗎，當然是不可能的，這樣的融法會出現以下幾種可能 :

1. 水蜘蛛 or 褐土獅
( 融了結果還是沒變，這是最最最常見的 )

2. 挖土蜘蛛
( 土獅的屬性跑到蜘蛛去了 ... 跟期望的水獅子不同，失敗 )

3. 藍獅子
( 水蜘蛛的屬性跑到獅子去囉！大成功 )

4. 突變
( 也就是三個問號，產生出一隻無法預測的寵，什麼可能都有 )

1. 跟 2. 都算是失敗，3. 才是我們希望的結果，但是 4. 呢 ... 因為突變會出現的寵真的是隨機的，也有可能變成一隻垃圾寵，當然也有機會變成一隻夢幻的稀有寵 ... 所以這個只能說是靠運氣了， 不過突變的機率真的很低，大家也不用太在意，只是要融合真的要有心理準備，為了融某一種寵而花了 10 幾組的寵也是有的 ( 譬如說抓了 10 隻水蜘蛛跟 10 隻褐土獅來融，發誓要融出藍獅子 )， 只能祈禱好運降臨，一次就融出心裡想要的寵囉，祝大家都能順利融合成功 : )

3. 彩色田的鄧肯爺爺 45,240 說只要給他 10 根黑壇木，就可以給你一束稻草，這個任務一共要 20 束稻草，也就是要 ... 200 根黑壇木 @@"" 雖然說在彩色田打綠尾鳥也會掉黑壇木， 不過還是請人掛好再來解吧 ... 黑壇木也很重 ...

4. 總算收集好 20 束稻草後回去找稻草人，就可以完成這個任務


【陽光森林深處】

支離破碎的鐵樵夫
等級限制：無 獎勵：找阿古爺爺修：15000 經驗、1500 聲望
盔甲技能50自己修：20000經驗、2000聲望		 附註：需解完夢奇金的稻草人
名聲限制：無 職業限制：無
1. 在陽光森林南邊 31,368 可以看到一堆木材，點一下就可以進入陽光森林深處，在裡面可以看到 ... XD 可愛的鐵樵夫，剩一郭頭而已 ~ 隨便想也知道 ... 這任務就是要幫他將身體零件找回來囉

2. 回到彩花村打黃飛猴就會有機會取得鐵樵夫身體零件『身體、左手、右手、左腳、右腳』五個零件，打滿五個之後就可以回去找鐵樵夫囉

3. 收集好零件回去找鐵樵夫，卻發現零件已損毀需要修復，於是這時有兩個方法幫助鐵樵夫 :
一. 準備『鐵塊 * 4、鋼塊 * 3、鋼條 * 1』去翡翠城 73,206 的裝備修理店裡面找阿古爺爺修
二. 『盔甲製作』工作技能 > 50 級就可以自己來修，但還是要『鐵塊 * 4、鋼塊 * 3、鋼條 * 1』

4. 修組好零件後跟鐵樵夫說話，卻發現他要加油加油了 ( 是真的要加油 = = ) ... 於是幫他到陽光森林 54,73 的小木屋內，右上方有很多木桶，點最右上最邊邊那個就可以拿到油壺了

5. 帶著油壺回去幫鐵樵夫上好油後，這任務也完成囉

解救膽小獅
等級限制：無 獎勵：30000 Exp、20000 可因、健保卡 * 1、三封 * 1 附註：需解完支離破碎的鐵樵夫，若不跟桃樂蒂講話直接點右邊傳送石打倒膽小獅，則任務並不會解，還是要回去跟桃樂蒂講話再跟膽小獅打一次

威奇魔法陣迷宮走法
名聲限制：無 職業限制：無
1. 在威奇迷宮B2 ( 39,87 ) 跟可愛小貓咪說話，牠會說牠是威奇女巫的護衛長豹將軍 ... 於是變回原形花豹進入戰鬥 ~

2. 打贏牠之後，牠會告訴你進入威奇魔法陣的密門跟通關咒語，來到威奇迷宮B2 ( 65,16 )，點上面的牆，就可以進入威奇魔法陣

3. 傳來傳去最後會碰到桃樂蒂，她會告訴你膽小獅已經被下了傀儡咒，並告訴你解咒的方法，叫你去解救膽小獅

4. 點選桃樂蒂右邊的傳送石就會來到膽小獅面前，打倒牠之後就可以獲得封印起來的膽小獅

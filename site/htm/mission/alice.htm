【紅帽村】

尋找愛麗絲
等級限制：無 獎勵：100 聲望、傳送粉末 * 1 附註：無
名聲限制：不明 職業限制：否
1.去找紅帽村的派翠西亞 ( 一進去紅帽村就看的到 )，他叫你去找豌豆湖打聽愛麗絲的消息。

2.去豌豆湖問鄧肯(13.106)，他說去問挖土蟲夏魯。

3.去找挖土蟲夏魯(8.125)，他說愛麗絲跑到西迷路森林去了...

4.到西迷路森林找貓頭鷹妮可(68.97)，會發現度度鳥溺水了，和右下方的度度鳥說完話之後，牠會要你去夢想花園找挖土蟲康納拿鳳梨果汁。

5.回夢想花園找挖土蟲康納(13.55)，他叫你去找：桃子 5 顆、薄荷 5 片、4 瓶水果酒和 2 瓶醋 ... 拿給他以後就可以取得鳳梨果汁。

6.回去跟度度鳥說話，他會說要泡泡腳，並給得到100聲望和傳送粉末。

青蟲與白鳥

名聲限制：無 職業限制：無
1. 去找西迷路森林的遲到兔，他會叫你去找青蟲康康。

2. 在西迷路森林會找到青蟲康康(10.347)，他會依對話選擇，選擇是第 4 的那個把你變成一隻新寵，然後去找白鳥恰吉

名聲限制：無 職業限制：無
1. 跟玫瑰園右下的撲克牌士兵迪克講話(66.217)，他會叫你去南貓咪森林找卡樂買 20 罐紅色染料

2. 來到南貓咪森林左上跟卡樂說話(8.92)，他會要你參加競標紅色染料 ...

競標時間是每天早上 8 - 11 時 ( 童話時間 )，卡樂會說這次競標 n 瓶，叫你出個價然後再比誰出得高由誰購得 ( 暗標 )。

一天只有標一次機會，一般來說大概是他說這次標 n 瓶 ... 你就出 n * 11000 的價錢，譬如他說今天標 6 瓶 ~ 你就出標價 66000 ... 但有時其他 NPC 會很 @#%!^@^& ~ 出更高 ~ 所以如果不想浪費時間 ... 出 n * 11000 再多個 3000 比較保險 ... 不然又要再等一天 = =

不用擔心會多標，系統會正正正好讓你標到 20 瓶整 ... 但是最後剩下要標少少幾瓶要出多一些價錢 >_< ... 像站長最後剩 2 瓶 ... 出了 25000、26000 都標不到 ( 又浪費在遊戲裡等兩天 ... !@#!%@#^ ) ... 所以最後出 27500 才標到 ... ( 也就是 n * 11000 + 5500 ... )，但是有志者事竟成，一直出少錢總是會標到的嘛 ... 只是這任務真的太浪費時間跟錢了 ... 為了買那十萬的經驗 ... 這任務可以列為童話肚爛任務排行榜前幾名吧 ...

以保守估計解這任務要 20 * 11000 = 220000 ... 22 萬 ~ 但是就站長的經驗 ... 除非你有夠多的時間跟系統耗 ( 非要出低價買 ) ... 不然大概要花個 25 萬左右吧 ...

3. 將紅色染料拿回去給迪克，他就會交給你牢房的鑰匙，任務也到這邊告一段落

保球一族
等級限制：無 獎勵：10000 Exp、4000可因、200聲望(村長傑夫給的) 附註：需解完鳳梨山的被搶奪的銀球，百年通天草解完任務可取得，若如期在遊戲時間一個月內收集好小雪要的材料她會說你守時並得到50點聲望
名聲限制：10000 職業限制：無
1. 小雪(13.24)跟你說他父親得了老人癡呆，要你收集百年通天草、月葵*10、羌子肉*3、老薑*3、鱉*2、高梁*5 這五樣東西做藥

2. 把這幾項藥材收集好交給小雪，等了一會她會說要正百年通天草，並叫你去找鳳梨的泰伯特拿

3. 鳳梨山的泰伯特(20.217)會叫你去跟小雪拿金球來交換正百年通天草

4. 回去跟小雪說明之後她會告訴你金、銀球的傳說還有問你金球還是救父親重要(選父親，選金球會被扣聲望)，然後她就會把金球給你

5. 把金球拿去給泰伯特交換到正百年通天草後再回去找小雪，她又會叫你等一下 ... 並說父親的病已好轉 ~ 得到獎勵，最後他會叫你去找她父親吉恩村村長傑夫

6. 去吉恩村市鎮中心跟村長傑夫說話得到 200 聲望，任務結束

邪惡的詛咒
等級限制：無 獎勵：40000 Exp、500聲望、10株正百年通天草(泰伯特) 附註：需解完保球一族，金銀神嘍囉都是法師系的魔王，金、木、水、火、土五個 ... 不難打，只會放法術而已 ~ 威力也不大，而最後打銀魔頭目他是闇使 ... 所以武化光第一時間秒掉他就沒什麼好怕的了 ~ 血才8000 ~ 組隊去打很輕鬆的
名聲限制：無 職業限制：無
1. 跟小雪講話她會突然向你攻擊過來(武鬥家吧 ~ 會破空拳但是不強)，打倒她之後可得到金色捲軸，點選捲軸後會中詛咒(詛咒好像會不一樣，有人是血不斷減少，有人是魔法最大值減少，而站長是血的最大值少7xx)

2. 去鳳梨山問泰伯特怎麼一回事他會叫你去問伊利村的傑夫卡

3. 找到伊利村外圍(25.25)的傑夫卡他會跟你要情報費(給一千、五千都不行 .. 要給一萬 ... 若點了一千或五千錢還是照扣喔 = = ... 就算點一千或五千給滿一萬他還是不會說，一定要一次點一萬 ...)，然後他會告訴你再回去找泰伯特(這任務這邊分明是 ... 莫名其妙的騙錢又浪費時間 \_/ )

4. 回到鳳梨山發現泰伯特很痛苦並告訴你趕快去史洞，來到史洞1跟金神嘍囉戰鬥(41.142)，戰鬥完他會說要解詛咒要去鼠洞找銀魔頭目

5. 到鼠洞B1打敗銀魔嘍囉(9.70)後最後再跟旁邊的銀魔頭目戰鬥，戰勝後在身上的詛咒就可以解除了

6. 回去找小雪交差後得到經驗跟聲望，她會叫你去找泰伯特 ~ 再去鳳梨山找泰伯特得到10株正百年通天草 ~ 任務結束

名聲限制：無 職業限制：無
1. 跟小雪說話他會叫你給他正百年通天草 10 株 ( 終於可以把這東西給她了 )，並且她會給你 10000 可因 ( 若選擇不收可以獲得 160 點聲望 )，之後她會給你強力封印球叫你去封印金愛掃

2. 來到史洞三樓史王處遇到金愛掃(40,109)，跟他交談進入戰鬥，是一個 60 級魔王跟四隻史王，會拼命幫史王補血卻不常幫自己補或攻擊的魔王，只要人多或是覺得史王不可怕應該就可以輕鬆解決他

3. 打贏魔王回去找小雪，獲得獎勵，這時她會跟你玩猜數字的遊戲，若越早猜中數字獎品越好 ? 站長猜六次猜中，得到十碗十全鱔湯，另一個家族的人猜七次，得到一萬可因 ~ 任務結束

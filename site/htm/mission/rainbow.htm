New 減肥中的國王 New
等級限制：無 獎勵：10000 Exp、10000 可因、五瓶解毒劑 附註：無
名聲限制：無 職業限制：無
1. 跟彩虹城(196,514)老大臣說話後，他會要你去找彩虹城醫院的哈得大夫求減肥藥

2. 來到彩虹城醫院(207,685)裡面找哈得大夫說話，知道他的醫療箱被搶走了，要你去幫他找回來

3. 到夢幻花園的(8,117)打倒如花叫出來的恐龍妹(Lv40血大約一萬吧，很爛很爛~不用擔心)之後取回醫療箱回去找哈得大夫，他會叫你去玫瑰湖找美花婆婆

4. 在玫瑰湖(33,258)跟美花婆婆講話，他要你打波里系的幻獸去收集五色旗

綠色加油旗子 - 打碗豆湖的木頭波里
藍色加油旗子 - 打金銀湖的加油波里
金色加油旗子 - 打金銀城外 ( 靠近往神燈沙漠 ) 或鼠洞B2的高登波里
黃色加油旗子 - 打南綠野的土波里
紅色加油旗子 - 打哈啾島的熱血波里

5. 取得五色旗回去找美花婆婆就可得到減肥藥，回去交給老大臣任務就可以完成囉 ~

P.s 這個任務是站長參加國王的新衣資料片任務徵選得獎官方採用改編的喔 ^^~

New 國王的新衣 New
等級限制：無 獎勵：
結局一：五萬經驗值、一萬可因、一千聲望
結局二：超級經驗娃娃、三十萬經驗值、三萬可因、三千聲望
結局三：經驗娃娃、二十萬經驗值、兩萬可因、兩千聲望
 附註：需解完舞會前的準備
名聲限制：無 職業限制：無
1．任務起點–彩虹城裁縫店的皇家裁縫師，他會請你幫忙問國王為什麼不滿意他的衣服。
2．到皇宮外找老大臣講話，他會給你一張進入皇宮的通行證。
3．和皇宮門口右邊的守衛說話，給他通行證後就可以進入皇宮。
4．走到皇宮的最裏面發現有個守衛在睡覺而且叫不醒，到皇宮中間問其他守衛怎麼叫醒他。
5．守衛告訴你只有御廚叫得醒他，可是御廚去釣鱸魚。所以要去各個可以釣鱸魚的地方找他。
6．一共有四個地方可以釣鱸魚，御廚會一直換地方。

北綠野–18．18
玫瑰湖–50．241
矮人山–23．157
紅帽村–27．34

 7．找到御廚後，他會叫你帶10條黃魚給他（先準備好吧，不然他一直換地方很難找）。
8．給他黃魚之後，他就會教你叫醒守衛的方法。
9．回到皇宮叫醒守衛便可以見到國王了。
10．和國王說話後才知道他只想穿著內褲@@"。
11．到裁縫店找皇家裁縫師，他會叫你去找做內褲的材料。

守護天使的翅膀*1–大盜巢穴b2 神氣獅鳩的羽毛*10–沙皮島 外加一碗十全鱔湯、鮮花一朵

 12．收集完後去找皇家裁縫師，等三天之後去找他拿內褲。
13．將內褲拿給國王，國王說皇后不准他穿。這時候會有兩個選項：

第一個是從現成的衣服中選一件。（任務結束–結局一，當然不要選！！）
第二個是幫他配衣服，分別為頭部、衣服、褲子、鞋子四類，每一類有四個選項可以選，選完之後國王會評分。

 14．找皇家裁縫師做衣服，隨著配衣服分數的高低不同，裁縫師會告訴你要收集哪些材料。

80分以上–厄斯女妖的衣服（遺跡十樓）和陳年高梁一瓶。
80分以下–法亞女妖的衣服（遺跡七、八樓）和陳年紹興一瓶。

 15．收集完材料去找裁縫師，得到國王的新衣。
16．拿去給國王後，任務結束（根據配衣服的成績給獎勵，80分以上為結局二、80分以下為結局三）

Ps 1．

提供我配的衣服給大家參考（80分以上的）

　頭部–絲襪
　衣服–肉色緊身衣
　褲子–超人內褲
　鞋子–男子漢木屐

Ps 2．

這個任務的確需要等級高一點才好解，
因為最後需要的材料--女妖衣服要到地下遺跡去打怪，
配衣服80分以下要打遺跡七、八樓的法亞女妖--要經過三、六樓的王，
配衣服80分以上要打遺跡十樓的厄斯女妖--要經過三、六、九樓的王，
其實要打王還不怎麼難，組隊的話都滿好過的，
更難的是你最好有單p8x級怪物的能力，
因為大家都知道--單p比較會掉材料，組隊要打很久。

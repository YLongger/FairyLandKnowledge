站長的話
這裡是童話安徒生『敗家一族』的家族網站， 雖說是家族網站，不過是一個適合所有童話人的地方，自從決定要做這個網站，就一直都很努力在做，希望可以把資料給整理的很完全， 因為當初第一次接觸到童話是在資訊展的會場，拿到一片免費的光碟 ...

我之前也是遊戲基地的麻煩人物，一直在基地童話區波文章問一些呆問題，現在已經玩了一陣子，看到精華區那麼多高手整理出如此詳細的資料，真是現在新手的福音， 所以我也想把這個網頁資料區給弄好，讓新手可以順順利利在這裡找到所需要的資料，和官網沒有的東西，甚至是我們這邊自己獨家提供的 ^^

以前在神州有個很好的站叫做神夢 ... 是每個神州新手的家，現在來到了童話，也希望能夠在這裡築成一個童話新手的家，能帶給各位幫助的地方， 當初是風無痕創的家族，雲影建議一起來做個網頁 ... 於是天之子就開始動工 ...希望也能做出一個不辱神夢網站的水準 ... 現在還在持續努力當中 ... ... ...

從高中以來就沒好好認真做一個網頁，這個網頁不只是家族的網頁，也是站長自己一個努力的起點，一個對自己的考驗跟交代，所以我會盡全力把這邊用好， 只要有不好的地方希望大家跟我說，這裡會不斷地更新改變成長的 ~ 也希望各位及家族成員多多支持喔 !

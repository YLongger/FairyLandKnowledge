人魚傳說新地區

首先先往第一個新地區 - - - 尼克草原出發，位置在吉恩村東北方 ~

會在橋頭看到一個 " 貝伯港大使 " 在貝伯港也同樣有一個吉恩村大使可以花錢直接傳送 ~

價錢不便宜喔 ~ 是 : (等級-10)*100

尼克草原一路往東就是貝伯港了，在貝伯港可以通往米夏島及史蓋窩克海 

往米夏島在右下方跟老船長講話就可傳過去了，只是還是要花錢

但是可以多人組隊一起傳 ~ ( 多人還是會貴，但會打折 @@a 不過不像六大島一定要分開 )

以下是筱迷網友熱心提供的價錢數據 :

1人:2000
2人:3200
3人:4800
4人:6400
5人:8000

因為團體價有打八折喔~
記算方式:
2000*2=4000>4000*0.8=3200
2000*3=6000>6000*0.8=4800
2000*4=8000>8000*0.8=6400
2000*5=10000>10000*0.8=8000

而在貝伯港最右邊有個巫師你給他氧氣泡泡糖他會幫你傳到海中 ~

泡泡糖取法請在人魚傳說的新區域打打新怪 ~ 會掉一堆冰的材料 ...

以下是做冰所需的材料 : 

香蕉船 香蕉、牛奶、巧克力、草莓、鳳梨、蛋 
聖代 牛奶、巧克力、草莓、麵粉、蛋 
優格冰淇淋 優格、牛奶、草莓、麵粉 
甜筒 牛奶、巧克力、草莓、麵粉、蛋 
特製甜筒 牛奶、藍莓、草莓、芒果、麵粉、蛋 

收集好材料去貝伯港的冰品店(30,226)找貝美叫她幫你做冰

然後把隨意一種冰拿給米夏島左上方的傑克，就可以隨機獲得『氧氣泡泡糖』或是『紅豆』

米夏島東方有個傳送點，進入後是巴斯迷宮 B1 ... 然後順著迷宮是 B2、B3 ~

到了巴斯迷宮 B3 再下去就是趴趴迷宮 B1 ... B2 ... B3 ...

過了趴趴迷宮 B3 之後就可傳到了恐怖的 " 史蓋窩克海 B1 " ...... 

大家加油組隊去探險吧 @@ ~ 但是別忘了去海裡要帶著氧氣泡泡糖喔 ~

不然無法從趴趴迷宮 -> 史蓋窩克海 B1

以下是新地區的等級 :

尼克草原 : 11-15
米夏島 : 16-20
史蓋窩克海 : 21-25
巴斯迷宮 B1 : 36-40、巴斯迷宮 B2 : 46-50、巴斯迷宮 B3 : 51-55
趴趴迷宮 B1 : 56-60、趴趴迷宮 B2 : 61-65、趴趴迷宮 B3 : 66-70
史蓋窩克海 B1 : 71-75、史蓋窩克海 B2 : 76-80

祝大家探險愉快喔 ~

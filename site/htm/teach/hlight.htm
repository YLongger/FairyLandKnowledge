家族之光介紹

家族人數滿 25 人，三大城家族管理人員有賣『家族之光』集卡冊，一本是5萬可因 (只有大頭目可買) 
 
所須卡片 : 金屬史萊姆、樹蛙、水窩蟲、紅木偶、土撥鼠、光瓢、邪惡禿鷹

推薦打卡地點 :

金屬史萊姆 : 史洞二樓

樹蛙 : 玫瑰湖、青蛙沼澤 ( 最難打的一張 ... 也是屬於數十萬的價錢 @@ )

水窩蟲 : 玫瑰湖、青蛙沼澤

紅木偶 : 北方洞窟 ( 解動物之家木偶山那 )

土撥鼠 : 鼠洞2F

光瓢、邪惡禿鷹 : 西綠野

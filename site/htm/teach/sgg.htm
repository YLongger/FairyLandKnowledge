有關神殿信仰的用途與應該要練多少

首先介紹神殿信仰的功用

簡單地來說，就是提升該法術系的傷害數值 ( 成功率 ? )

不過經過許多熱心網友試驗，最好只信仰單一系的神就好了

像法師就比較頭大了，因為最好只挑一系來信仰

不然信仰的加成會被分散

假設信仰 100 可以加威力 100、信仰 50 可以加威力 50 ...

同時信火神 100 跟信土神 100 ... 

卻會變成火系法術威力 + 50、土系法術威力 + 50 ( 兩神分掉了 )

至於信某種神身上的屬性 ( 攻擊屬性與防禦屬性 ) 會變為該屬性

並不會因為信仰神而讓屬性加成增加喔 ~

就是說，假設信火信地再高，身上火屬性打金還是只有多 50% 傷害
( 不過這沒什麼關係，武化跟鎧化之後屬性就蓋掉了 )

並不會因為火信仰信地很高，而火性相剋就變得高

再來，

衝信仰值衝過 14 萬之後，效果就會漸漸下降

但並不是完全沒有效，只是效果沒有一開始衝增加地這麼明顯

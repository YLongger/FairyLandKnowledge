新手升級裝出現 !! 你欠裝備嗎 !?

在貝伯港的右下方多出了一堆 NPC

他們就是販賣各種武器、防具的商人 ~

等級在 10 - 50 級之間，唯一特別的是裝備都會附加一點屬性 ( 好像就只有一點 )

屬性有可能是六大屬性或是命中率、防禦率這些的

不過所謂 NPC 賣的 ... 當然不會比玩家好

價錢貴、耐久『極』低 ... 還有數值也很爛 ...

But !! 重點是，在低等裝備並沒有增加屬性的裝備

像手套，要到等級 50 才有屬性手套出現 ( 要加體就必須用有洞鑲體寶 )

但是卻可以在這邊買到加體的手套

( 有玩家買到 +3 的過 ~ 不過很難買吧 @@? )

所以升級帶體裝應該是會多點血，從新手時就買一整套體裝吧

雖然都只有加一 ... 但是全套下來也有加個四、五點體或智吧

不過要賭就是了，並不是一買就是你想要的屬性

所以要多賭幾次 :P ( 當然可因也要夠多 )

若單純只是要買裝備練功的玩家，站長建議各位 :

可以上電台問問大家有誰在做裝備

因為其實會做裝備的人很多，但是可能他們都懶得掛在商場等人買

所以不如你去打聽打聽這些人，有需要的話用飛鴿給他們私下訂購

相信只要你客氣一點，跟他們混熟的話，價錢一定是又便宜數值又好

至於新手裝的話，就可能要自己去收集材料

因為你去找高手做新手裝，他們可能也懶得跟你收那一點錢

而新手裝的裝備材料如果能自己收集給他們的話

我想他們應該會願意幫你製作的，所以新手自己也要掛一下工作技能

有了材料，再去問有沒有人願意幫你做

材料都收集好了，幫你做又可練工作技能 ~ 相信應該不難找到好心人 :)

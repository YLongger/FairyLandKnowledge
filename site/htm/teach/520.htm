以下資料由家族拋頭顱灑熱血還有網友提供 : ( 感激各位犧牲 Q_Q )

沉睡村(10.153) → 椰子島 ( 怪等 41 - 50 )

秘密平原左上屋子右邊(47:46) → 哈啾島 ( 怪等 46 - 50 )

天鵝湖左上→鬱金香島 ( 怪等 51 - 55 )

金銀湖右下(72.206) → 咕嚕島 ( 怪等 55 - 60 )

矮人山左下(6.113) → 聽說島 ( 怪等 61 - 65 )

玫瑰湖水神殿旁邊 → 玫瑰島 ( 怪等 66 - 70 !! 敏超過 102 )

上述地點傳送都需金錢，而傳送錢的多寡是依個人聲望而定，

價格如下 :

椰子島 : 1000 + (13000 - 聲望) 
哈啾島 : 1000 + (14000 - 聲望) 
鬱金香島 : 1000 + (16000 - 聲望) x 2 
咕嚕島 : 1000 + (19000 - 聲望) x 2 
聽說島 : 1000 + (23000 - 聲望) x 3 
玫瑰島 : 1000 + (28000 - 聲望) x 3 

當然不會有負數 ~ 最少還是要花 1000 元傳送

而且只能個人，不能組隊進去，所以進去前請解散隊伍

獎賞 : 100 經驗值
                                                                                
任務種類 : 1. 在限定時間內，打敗20隻不限等級的幻獸
　　　　　 2. 送東西給指定的 NPC

怕商場太lag嗎 ? 請按下 alt+m 系統選單有個大家都不見 !!

這樣就不用擔心什麼商場一堆人在做動作而造成 lag 了，只看到展示架而已

三大城家族管理人員有賣『家族之光』集卡冊，一本是5萬可因 (只有大頭目可買) 
 
所須卡片 : 金屬史萊姆、樹蛙、水窩蟲、紅木偶、土撥鼠、光瓢、邪惡禿鷹

不定期會出現保衛戰 !! 每次需要玩家為 lv 10-15，16-20 ... 一直到46-50 ~

喊到若你符合該等級內請快到第三伺服器的該城(他會說哪個城)皇宮內報名，只有30名額

進入村子場內會有四個口會出現敵人，要在時間內阻止他們進來，拼命戰吧 !!

戰鬥隨機可能得到 "打不開的箱子" 可去依利村寶石店開喔 ^^ ~ 祝打寶戰鬥順利 ~

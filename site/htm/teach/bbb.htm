大至來簡單介紹一下，首先要換造型就是你必須得要二轉 ( 也就是 60 級囉 )

接下來去國王的新衣資料片瓦尼島，從巴斯拉港最右邊有個船長可以傳過去

船票挺貴的 ... 不能組隊 ~ 要解散隊伍再點船長

到了瓦尼島，建議最好組隊前往，因為島上的敵人都是 65 以上 ...

瓦尼島地圖很大，不過其實按 Ctrl + N 打開大地圖就可以發現

路只有一條，繞到左邊進入島中央，就可以進入這次資料片開放的新迷宮

一路往迷宮裡面走 ( 前幾層迷宮看到門就直直走進去就是下一層了，不是用點的 )

到了迷宮 3F，在中間會看到一個無尾熊祕書 ( 魔王也要請秘書 = = )

組好隊點他就可以進入房間內跟魔王 - 大可獸壹號戰鬥

不過注意，點秘書的時候一定要組好隊跟決定好隊長

不然進去房間再重新組隊換隊長時，魔王會說你沒預約就把你傳送回迷宮一開始喔 !!

而且當房間裡面有其他人在打魔王時秘書不會讓你進去，只好在外面等

這時建議你可以換個伺服器等等看

再次提醒 ~~ 點秘書時一定要組好隊喔 !! 不要進去再重組 ~

打完魔王後就可以取得職業徽章了 !! 但是 ...

只有隊長可以得到呀呀呀呀呀 ~~~

所以你必須再重新再進一次迷宮換隊長再打一次囉 ...

站長是將點設在巴格達重新跑一次 ... 

因為打完魔王不是傳出迷宮而是到 4F，不知道能不能從 4F 傳回 3F ...
( 等待有人跟站長說囉 )

拿到徽章之後，並準備好材料跟自己職業的證書 
( 什麼 !? 不知道材料跟證書 ?? 上面有給你網址呀 ~~ )

就可以去巴格達城服裝店裡面找 NPC 換裝囉 ~

啊對了 ... 材料還少說一樣 ... 還要準備 20 萬可因給 NPC ... 

至於到底千辛萬苦變了造型有什麼用呢 ... 嗯 ... 嗯 ... 嗯 ...

答案是沒有用的 @___@ ( 目前啦 ... 不知道日後會不會改 )

要是你嫌新造型不好看也可以不要換造型呀 :P ~ 
( 什麼 !? 不知道造型長什麼樣 ?? 上面有給你網址呀 ~~ Q_Q )

喔喔喔對了 !! 魔王大可獸壹一號 ~ 血高達九萬多 ~

會 456 定身跟一堆有的沒的法術 ~ 還會召喚冰龍打一排 ~ 威力有兩千多 !!

最好先讓闇使用生命儀式消掉 1 / 5 法術或是用巫師的血液蒸發來打 ~

如何養出心目中理想的幻獸

" 降級重練 "目前是唯一的方法，所以站長在這邊 從巴哈姆特向 " Aironray " 板友借了一點資料放到網頁上 ( 我已經被著作權給用怕了 = = )， 每個幻獸剛抓來時屬性都是差不多平均的，想練出究極幻獸 ... ( 超暴力量寵、智慧寵、無敵肉墊寵 )， 就必須要把幻獸降級從等級 1 開始練，但是不但是幻獸的七大屬性會影響幻獸的成長點數分配，連 幻獸的外型都會有影響 ... 為什麼我們需要了解這些數值呢 ? 因為這邊可以讓你參考說到底要不要降這隻寵， 會不會這隻寵剛抓來是 3x 級 ... 降了雖然會等級 1 的屬性比較高一些 ~ 可能以後再練到 3x 會強一點 ... 但是點數分配會不會亂分配 ? ( 譬如說你想練暴力量寵 ~ 重新降級土獅子 ... 結果重練變成幸運獅 XD )， 所以在這邊大略介紹一下幻獸的成長趨勢 :

先由屬性 : ( 這邊是基地跟巴哈大家討論出來的結果跟家族感想 )

金屬性寵物 : 力量、體質 ( 範例 : 窩捲蟲 )
木屬性寵物 : 體質 ( 範例 : 拾木鼠 )
土屬性寵物 : 幸、體質 ( 範例 : 土萊姆 )
水屬性寵物 : 敏捷 ( 範例 : 水蜘蛛 )
火屬性寵物 : 力量 、小偏幸( 範例 : 紅瓢蟲 )
光屬性寵物 : 平均，不包括魅力 ( 因為是平均，所以無範例 ... )
闇屬性寵物 : 智慧 ( 範例 : 黑綿羊 )

這邊的資料都僅供參考，並非完全正確 !! 每個人多少還是有差異的 ~

上面都是從精華區裡，各版友降級重練的經驗整理出來的
雖然有些幻獸只有單一屬性(雪怪.兔兔)不過比較2種光寵之後
光兔應該是平均偏敏捷 => 兔兔是敏捷
雪怪則是平均偏體質 => 雪怪是體質

有些很明顯...有些不太好分辨
像獨角獸-光-平均偏智慧
      -闇-智慧力量獨高 => 所以獨角獸是智慧
這有點...獨角獸那麼聰明(又可愛)為何不會放法啦>.<

瓢蟲-光-平均偏敏捷
    -闇-智慧最高敏捷第2
    -火-力量最高敏捷第2 => 瓢蟲是敏捷

根據這論點~"~

   偏力量體質就是金的特色~所以分辨不出岩石怪屬啥

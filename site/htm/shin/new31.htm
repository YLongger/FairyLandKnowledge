【如何提升傷害力？】
先參考一下傷害力的計算公式：【武化後的傷害力計算公式】

(武器本身傷害 + ((武器本身傷害x斧技) / 50) + 力量x2 ) x (武化寵物力量/ 200) +
 (武器本身傷害 + ((武器本身傷害x斧技) / 50) + 力量x2 ) +幻化傷害+斧類武器傷害

總括來說, 要提升傷害, 就只有三大來源：斧勁、技高、寵勁
我就先說明這條公式的奧秘, 大家可能覺得, 點解低lv既時候, 升1lv斧技加得1-2個傷害？
e+解答你 -_-（真廢話多xd）高lv既時候, 用既斧正常係越高傷, 睇番條公式, 
斧技果一忽：((武器本身傷害x斧技) / 50) 武器傷害x斧技, 即係話, 如果你武器越高傷, 
同斧技既積乘加乘既幅度會大大提高。而且, 點解我話唔好加力？因為力量無任何變數同佢有乘積既加幅, 
力量x2 = 直接加去傷害。咁大家e+應該知道, 點解寵力量咁重要, 

因為睇番條果個公式：
(武器本身傷害 + ((武器本身傷害x斧技) / 50) + 力量x2 ) x (武化寵物力量/ 200) 原來係乘番埋個武化寵物力量, 
所以武寵力量同埋傷害有個比例。

總結：首先要有勁斧！有勁斧既話，升斧技同埋升寵得出黎既效果越好。
我e+用緊一把斧真斧 812傷, 每升1lv斧技大約up到50傷左右..

想要投稿給站長的朋友，麻煩在各個職業攻略內容裡面大概有以下幾項重點 :

1. 職業特色
   寫出你為什麼選擇練這職業
2. 建議種族及配點
   屬性配點對於新手來說是很重要的教學攻略，所以希望大家務必加上這點
3. 練功過程
   你是怎麼練上來的呢 ? 不要只寫 "找高手帶你練" 這樣完全沒有攻略價值
4. 二轉之後的改變
   這次新加上這個重點，原因是童話職業在二轉之後都有很大的轉變 ( 麻雀變鳳凰 !? )
   尤其是二轉之後的新技能，所以希望是由二轉玩家提供職業攻略這樣會比較詳細一些
5. 其他注意事項
   還有什麼要補充的都寫在這吧
6. 作者伺服器及 ID
   留一下你的大名吧

至於 "新" 也就是代表著新手上路的攻略

你要如何利用短短的一篇攻略來讓新手們可以快速地融入這個世界呢

這就是這一篇攻略的重點 ^^

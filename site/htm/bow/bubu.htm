☆推車新手上路☆
 1. 你要有一隻等級 5 並且到萵苣村找大力士-阿淦(35.148)，學會推車的寵

2. 到彩虹城彩虹城旅人工會找裴洛先生選擇製作你想要的推車種類

3. 將指定材料交給裴洛先生，你就可以得到一輛推車

4. 將推車如同幻獸配件般裝備到幻獸身上，並獸化此幻獸

5. Ctrl + C 開啟幻獸選單，點選幻獸技能 -> 推車，就可以讓幻獸推著你到處跑囉

推車的功用
 1. 回復體力跟法力會比較快

2. 在推車狀態下可以減低遇敵機率 ( 配合降遇敵項鍊應該不錯 )

3. 裝備不同的推車款式可以幫助幻獸提升不同屬性點數

4. 掛網的時候用推車 ... 就不用擔心掛網寵一直吸魔吸到降親和了 ~ 真是太棒啦 !!!

☆第二級推車☆
 1. 製作地點是在『巴格達城的幻獸店裡』找凱勒

2. 第二級推車就是第一級推車的加強版 :

　->回復體力跟法力更快

　->降低更多遇的機率

　->加更多幻獸屬性

3. 要幻獸 15 級才能裝備，比之前要多了 10 級唷

☆第三級推車☆
 1. 製作地點是在『瓦尼島遺跡地下8F的 89,83』找亞特 ...

2. 第三級推車就是第二級推車的加強版 ...
( 降遇敵真的降很多，趕路好用，補的法跟血也很多 )

3. 要幻獸 25 級才能裝備，再加個 10 級 ...

☆第四級推車☆
 1. 製作地點是在『翡翠城 60,215』找瑪姬

2. 第四級推車就是第三級推車的加強版 ...

3. 要幻獸 40 級才能裝備，再加個 15 級

( 又貴幻獸等級需求也高 ... 應該會補很多跟降很多遇敵吧 @@ )

☆第五級推車☆
 1. 製作地點是在『翡翠城 48,215』找海德

2. 第五級推車同樣也是第四級推車的加強版 ...

3. 要幻獸 55 級才能裝備，再加個 15 級

( 這真的值得練啦 !! )

4. 會動了會動了 !!! 推車終於會動了 !!! 車子會動喔 !!!

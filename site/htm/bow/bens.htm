我試了羊咩咩而已(因為自己對羊有種瘋狂的熱愛)

所以把22隻都調出來放在不同的人物裡

金  +  水  =  粉紅(像年獸)
金  +  土  =  粉紫
金  +  光  =  粉綠
金  +  闇  =  粉藍(跟潛水羊很像)
木  +  水  =  粉紅(比年獸深一點)
木  +  火  =  淺橘
木  +  光  =  深紫(有點東方神秘色彩)
木  +  闇  =  粉紅(沒年獸淺  也沒木+水深 應該說淺桃紅)
水  +  光  =  橘
水  +  闇  =  鮮黃(有點螢光綠)  
火  +  土  =  鮮綠
火  +  光  =  淺橘(跟木+火一樣)
火  +  闇  =  鵝黃
土  +  光  =  鮮綠(跟火+土一樣)
土  +  闇  =  紫

羊咩咩是這樣啦!但是聽說老鼠全部都是淺灰...(去變色得一定很想哭吧!)

by 格林 雨維(別來找我看羊,要一直開不同帳號,那樣很累)

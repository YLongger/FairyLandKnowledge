很早之前就人告訴站長說為什麼不把掉寶資料放到網上，

當時的怪沒那麼多，加上站長個人覺得童話的寶都是原料那些的 ... 好的寶就是娃娃跟卡，
不過每隻怪都一定會有機率打到該怪的卡跟娃娃 ... 實在不需要把它寫在網上 ~

如果說原料 ... 那也不用 ~ 工作技能就可以得到了 ... 那如果說是武器跟防具 @@ ，
更是不用，打怪掉的裝備不會比玩家辛苦練的製造技能做出來的還好 ...

所以就這樣這裡一直都沒有做 ... 一直到有天逛到了巴哈姆特的童話討論精華區，
看到了只有把原石掉寶整理出來的資料，站長覺得大概只有這個比較值得放吧，
所以就寄信拜託了巴哈的童話板主『Sunami』大大，她也很阿沙力願意讓我轉載了 ^^

其他的東西就是站長自己再整理出來的 ...

( 以上是舊版本資料 )

現在，幻獸會掉的所有東西站長也取得資料，放在『幻獸數值』這個單元囉
那這個掉寶資料雖然和幻獸數值有點重覆，不過卻是專門介紹特殊的寶物整理
所以我覺得分出來這個單元還是很有用的啦 :P

此外，原石不是只能由打怪取得喔，挖礦技能越高就越會挖到高級的原石，
所以有練挖礦技能又想挖到好原石的不妨加入公會，高等礦技加上高公會頭銜這樣原石挖到機率會增加喔。
( 我認識的一個朋友是挖礦100級，頭銜是挖礦之神，掛一天網下來身上都會有一堆奇奇怪怪的原石 )
這也是一個取得原石的方法，提供給大家做個參考 ~

但是 ... 現在新資料片開的練功區及新幻獸掉寶越來越好 ...
所以目前去新區打怪取得原石比掛網取得原石來得好多了 @@ ...
( 以姆指姑娘的夢奇地來做比喻 )

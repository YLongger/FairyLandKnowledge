什麼是幻獸娃娃
在更新成正式版之後，已經確定娃娃有變身的功能 ~

從基地的討論，可以知道這個有以下幾個作用 :

1. 變身 : 收集 " 五 " 隻同樣的幻獸娃娃 ( 最好是運氣那麼好 ... ) 和 5000 Coin 找白雪森林中的女巫就可以當天變身成該幻獸走來走去 ( 24 小時現實時間 ) ... 除此之外，在那天又打那隻幻獸，掉寶率會提升 ~ ( 但是後來大家變身後都沒有感到有提升打寶率 ... 所以到底變成幻獸是有什麼用 ... 搞笑嗎 @@ 唉 ~ 等官方來個說明吧 )

2. 收集 : 不論是什麼遊戲都會有收集狂 ... 所以不用多說 ~ 因為幻獸娃娃就跟掉卡片機率是差不多低的 ~ 所以自然娃娃也是有價值滴 ~

這些目前站長已知的作用，本來是要把娃娃放到幻獸百科那，不過排版起來會太擠了 ... 所以就沒有分類，就全放在這了，請大家見諒。如果以後有看到什麼新的消息會在這邊補上的，這裡也是一個娃娃的圖庫區，所以也就是說 ... 又要麻煩各位幫站長一起收集囉 ^^ ，下面就是抓圖的範例，跟資源收集那 的說明一樣，也是只要把他放在你的背包裡按下 Print Screen 就可以了，再寄信給站長 : )

3. 做玩具 : 開放了寵物玩具之後，幻獸娃娃還可以拿來加工增加玩具的屬性喔 ~ 詳細請看寵物玩具那篇介紹 :)

娃娃圖庫感謝大家的大力支持，因為沒想到會有這麼多圖，所以已經整理成依各個幻獸的種類排列，還有就是由左到右分別是 " 金、木、水、火、土、光、闇 " 因此有缺的地方大概就可以知道這是什麼寵什麼屬性囉 ^^

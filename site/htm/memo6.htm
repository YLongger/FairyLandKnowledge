裝　備　幻　化

　　簡單的說就是將你想要幻化的裝備跟幻獸帶到裝備店，然後請幻獸店小姐幫你幻化就 OK 啦，不過還是要付一點點的手續費啦，在一萬可因左右，看你裝備的等級而定。

　　不過要注意的是，幻獸等級跟裝備等級要是差太多的話不能幻化，還有幻化之後無法將幻獸再取回喔， 也就是說當你選好將幻獸與裝備融為一體時，這隻幻獸也將消失了，因此最好不要拿自己很寶貴的幻獸 來幻化，因為幻獸一幻化之後可是會永遠地離開你了。當然，這個裝備耐久度到 0 ... 壞掉的時候，也代表這幻獸 ... 幻化的裝備也永遠消失囉！

　　至於幻化會增加的屬性就跟你裝備類型有關係囉，武器就會增加攻擊力、命中率；而防具當然就是增加防禦力跟防禦率了， 而再看你幻化什麼屬性的幻獸，有時裝備也會附加上該幻獸的屬性，譬如你將一隻寶石獸幻化，這件裝備就有可能會附加光的屬性。

　　目前已知幻化之後增加的數值高低，是看幻化寵的智慧 !! 這真是很大的重點 ~ 所以有許多玩家已經開始重新養一隻智寵 ( 如小黑羊 )，養到 智慧兩百多再拿去幻化，武器傷害可以加 1xx 之多，幾乎可以說是多原本武器的一倍了 ... 所以現在重新養智寵可能又是一股熱潮了吧，反正現在又出了什麼寵物愛心棒的， 配合著寵物加油棒用，應該練寵可以練滿快的 @@ ~

　　至於幻化要選擇的裝備當然要是數值最好的囉，你拿一件不好的裝備來幻化不是很浪費那隻幻獸嗎， 還有要考慮到裝備耐久的問題，因為要幻化一隻幻獸，總不能拿個耐久低的裝備來幻吧，這樣裝備一下就壞掉了，也是很浪費， 所以除了要考慮到裝備數值的好壞，耐久度也是很重要的一點考量，要用得久幻化才划算呀！

裝　備　鑲　寶　進　化

首先大家可以來看看 這裡 下面的幾項寶石介紹

　　這個進化裝備的限制就比幻化來得難一些，因為一定要『有洞』裝備才能進行鑲寶進化， 而有洞的裝備可以參考工作技能的裝備那邊，有特殊屬性的裝備那邊最下面都有介紹，50、60、75級各有一種有洞裝備，只有這些裝備可以拿來鑲寶石， 不過寶石取得方式挺困難的，要靠打怪才有機會取得 ( 請參考童話攻略 -> 掉寶資料 )，而且掉落的機率可以說跟卡片一樣低 ...

　　其實這個進化方式不建議大家太期待 ... 因為鑲上寶石所增加的數值不是固定的，譬如說你鑲上一顆敏捷寶石，它增加的敏捷有可能是 1 ... 也有可能更高，所以要靠這些加屬性的有洞裝備， 不如去做一般的屬性裝備還比較便宜，這類的寶石又貴鑲上去又不一定是好的數值，所以只能說是 ... 鑲好玩的啦 = = ... 至於什麼防禦寶石 ... 鑲上去增加的防禦力跟防禦率 ... 真的是有夠糟的 ~_~ 不如你去 買隻幻獸拿去幻化這個裝備咧，不只寶石貴 ... 製造有洞裝備所需要的材料都是 80 級以上的產物 ... 所以目前鑲寶進化這項功能還不是說很普遍，大家也很少會用這類的裝備，拿去商場賣 ... 賣太低對自己來說又不划算，原料那麼難收集；不過 賣太貴又沒人買，與其買這類有洞裝備不如買普通的裝備還比較實用 ...

　　所以看看以後會不會這項功能，官方會有新的補充更新囉，不然暫時這種將裝備進化的方式對站長來講 ... 我是完全不會有興趣的啦 :P
